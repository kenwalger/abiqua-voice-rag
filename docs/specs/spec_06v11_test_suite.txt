Voice RAG System — Test Suite Specification
Spec version 1.1  ·  Component: Testing  ·  Status: Draft  ·  Updated: Cognitive Budget, record_url, EXPOSE_INTERNAL_ERRORS
Overview
This document specifies the test suite for the Abiqua Collection Voice RAG system. Version 1.1 reflects the current codebase: ImageGallery has been removed, record_url replaces short_url in the response envelope, the Cognitive Budget feature adds pipeline_cost fields to every /query response, and EXPOSE_INTERNAL_ERRORS and PIPELINE_DEBUG settings are now present.

The suite targets four high-impact areas: query classification logic, Pydantic schema contracts, Rime TTS integration error handling, and Cognitive Budget cost calculation correctness. All 37 tests run without live external API calls.

v1.0 changesImageRef schema tests removed (frontend type deleted, backend model retained). SCH-08 updated to test backend Pydantic ImageRef model directly. Added SCH-11 through SCH-14 for record_url, EXPOSE_INTERNAL_ERRORS, and CognitiveBudget. Added COST-01 through COST-07 for pipeline_cost.py. Added RIME-13. Total: 37 tests up from 32.
Testing Philosophy
CategoryDescriptionQuery classificationA misclassified query silently returns wrong data with no error raised. Highest-risk silent failure in the pipeline. Most important category to test.Pydantic schema contractsThe FastAPI request/response models are the contract between backend and frontend. Nullable fields, new fields like record_url and cognitive_budget, and error envelopes all need explicit validation.Rime integrationExternal API errors must map to correct HTTP responses. 429 from Rime must return 503. URLError must raise rime_unreachable. Testable with mocked HTTP — no live API calls.Cognitive BudgetCost calculation must be deterministic given known inputs. Pricing constants must produce correct USD values. The daily extrapolation must be mathematically consistent with total_cost_usd.

def make_source_meta(**kwargs):
    defaults = dict(model='.32 New Departure', serial_range='143960',
                    year_start=1905, year_end=None,
                    record_count=1, confidence=1.0)
    return SourceMeta(**{**defaults, **kwargs})

def make_cost_estimate(**kwargs):
    defaults = dict(embedding_tokens=8,
        narration_input_tokens=312, narration_output_tokens=89,
        tts_characters=387, collections_queried=1,
        routing_decision='serial_number',
        narration_model='claude-haiku-4-5-20251001',
        embedding_cost_usd=0.00000016,
        narration_cost_usd=0.00060560,
        tts_cost_usd=0.00619200,
        total_cost_usd=0.00679776,
        daily_cost_at_10k_usd=67.9776,
        pricing_date='2026-05-01')
    return CognitiveBudget(**{**defaults, **kwargs})

# tests/test_rime.py
import base64, json, pytest
from unittest.mock import patch, MagicMock
from urllib.error import HTTPError, URLError
from app.rime import synthesize, get_voices, _clean_narration, RimeResult

FAKE_MP3 = b'\xff\xfb\x90\x00' + b'\x00' * 100
FAKE_MP3_B64 = base64.b64encode(FAKE_MP3).decode('utf-8')

def make_mock_response(body: bytes):
    mock = MagicMock()
    mock.read.return_value = body
    mock.__enter__ = lambda s: s
    mock.__exit__ = MagicMock(return_value=False)
    return mock

class TestSynthesize:
    @pytest.mark.asyncio
    async def test_returns_rime_result(self):
        with patch('urllib.request.urlopen',
                   return_value=make_mock_response(FAKE_MP3)):
            result = await synthesize('The New Departure was produced in 1887.')
        assert isinstance(result, RimeResult)
        assert result.audio_mime == 'audio/mpeg'
    @pytest.mark.asyncio
    async def test_audio_b64_round_trips(self):
        with patch('urllib.request.urlopen',
                   return_value=make_mock_response(FAKE_MP3)):
            result = await synthesize('Test.')
        assert base64.b64decode(result.audio_b64) == FAKE_MP3
    @pytest.mark.asyncio
    async def test_uses_default_voice(self):
        with patch('urllib.request.urlopen',
                   return_value=make_mock_response(FAKE_MP3)):
            result = await synthesize('Test.', speaker=None)
        assert result.speaker == 'colby'
    @pytest.mark.asyncio
    async def test_uses_provided_speaker(self):
        with patch('urllib.request.urlopen',
                   return_value=make_mock_response(FAKE_MP3)):
            result = await synthesize('Test.', speaker='grove')
        assert result.speaker == 'grove'
    @pytest.mark.asyncio
    async def test_401_raises_api_error(self):
        err = HTTPError('', 401, 'Unauthorized', None, MagicMock())
        err.read = lambda: b'{"error": "invalid_api_key"}'
        with patch('urllib.request.urlopen', side_effect=err):
            with pytest.raises(RuntimeError) as exc:
                await synthesize('Test.')
        assert 'rime_api_error:401' in str(exc.value)
    @pytest.mark.asyncio
    async def test_429_raises_api_error(self):
        err = HTTPError('', 429, 'Too Many Requests', None, MagicMock())
        err.read = lambda: b'{"error": "rate_limit"}'
        with patch('urllib.request.urlopen', side_effect=err):
            with pytest.raises(RuntimeError) as exc:
                await synthesize('Test.')
        assert 'rime_api_error:429' in str(exc.value)
    @pytest.mark.asyncio
    async def test_url_error_raises_unreachable(self):
        with patch('urllib.request.urlopen',
                   side_effect=URLError('Connection refused')):
            with pytest.raises(RuntimeError) as exc:
                await synthesize('Test.')
        assert 'rime_unreachable' in str(exc.value)

Category 4 — Cognitive Budget Cost Calculation (7 tests)
Tests for pipeline_cost.py. Pure unit tests — no external dependencies. Validates that pricing constants produce correct USD values and that mathematical relationships between fields are consistent.

Design noteThese tests pin the pricing math, not the specific dollar amounts. If Anthropic or Rime update pricing, the PRICING constants in pipeline_cost.py are updated, the tests are updated to match, and the change is recorded in CHANGELOG. The tests exist to catch accidental changes to the math, not to assert that specific pricing is correct.
Test inventory
Test IDCategoryWhat it validatesCOST-01CalculationZero token inputs produce zero costsCOST-02CalculationEmbedding cost = tokens * embedding_per_token constantCOST-03CalculationNarration cost = (input * haiku_input_rate) + (output * haiku_output_rate)COST-04CalculationTTS cost = characters * rime_per_char constantCOST-05Calculationtotal_cost_usd = embedding + narration + tts (within float tolerance)COST-06Calculationdaily_cost_at_10k_usd = total_cost_usd * 10000 (within float tolerance)COST-07DataclassCostEstimate routing_decision and narration_model fields are preserved

# tests/test_cost.py
import pytest
from app.pipeline_cost import calculate_cost, PRICING

class TestCostCalculation:

    def test_zero_inputs_produce_zero_costs(self):
        result = calculate_cost(
            embedding_tokens=0,
            narration_input_tokens=0,
            narration_output_tokens=0,
            tts_characters=0,
            collections_queried=1,
            routing_decision='serial_number',
            narration_model='claude-haiku-4-5-20251001',
        )
        assert result.embedding_cost_usd == 0.0
        assert result.narration_cost_usd == 0.0
        assert result.tts_cost_usd == 0.0
        assert result.total_cost_usd == 0.0
        assert result.daily_cost_at_10k_usd == 0.0

    def test_embedding_cost_matches_constant(self):
        tokens = 100
        result = calculate_cost(
            embedding_tokens=tokens,
            narration_input_tokens=0, narration_output_tokens=0,
            tts_characters=0, collections_queried=1,
            routing_decision='serial_number',
            narration_model='claude-haiku-4-5-20251001',
        )
        expected = round(tokens * PRICING['embedding_per_token'], 8)
        assert result.embedding_cost_usd == expected

    def test_narration_cost_matches_constants(self):
        result = calculate_cost(
            embedding_tokens=0,
            narration_input_tokens=300,
            narration_output_tokens=90,
            tts_characters=0, collections_queried=1,
            routing_decision='serial_number',
            narration_model='claude-haiku-4-5-20251001',
        )
        expected = round(
            300 * PRICING['haiku_input_per_token'] +
            90  * PRICING['haiku_output_per_token'], 8
        )
        assert result.narration_cost_usd == expected

    def test_tts_cost_matches_constant(self):
        chars = 387
        result = calculate_cost(
            embedding_tokens=0,
            narration_input_tokens=0, narration_output_tokens=0,
            tts_characters=chars, collections_queried=1,
            routing_decision='serial_number',
            narration_model='claude-haiku-4-5-20251001',
        )
        expected = round(chars * PRICING['rime_per_char'], 8)
        assert result.tts_cost_usd == expected

    def test_total_equals_sum_of_parts(self):
        result = calculate_cost(
            embedding_tokens=50,
            narration_input_tokens=300,
            narration_output_tokens=90,
            tts_characters=387, collections_queried=1,
            routing_decision='natural_language',
            narration_model='claude-haiku-4-5-20251001',
        )
        expected_total = round(
            result.embedding_cost_usd +
            result.narration_cost_usd +
            result.tts_cost_usd, 8
        )
        assert abs(result.total_cost_usd - expected_total) < 1e-9

    def test_daily_extrapolation(self):
        result = calculate_cost(
            embedding_tokens=50,
            narration_input_tokens=300,
            narration_output_tokens=90,
            tts_characters=387, collections_queried=3,
            routing_decision='natural_language',
            narration_model='claude-haiku-4-5-20251001',
        )
        expected_daily = round(result.total_cost_usd * 10000, 4)
        assert abs(result.daily_cost_at_10k_usd - expected_daily) < 1e-6

    def test_metadata_fields_preserved(self):
        result = calculate_cost(
            embedding_tokens=8,
            narration_input_tokens=312,
            narration_output_tokens=89,
            tts_characters=387,
            collections_queried=1,
            routing_decision='serial_number',
            narration_model='claude-haiku-4-5-20251001',
        )
        assert result.routing_decision == 'serial_number'
        assert result.narration_model == 'claude-haiku-4-5-20251001'
        assert result.collections_queried == 1
        assert result.pricing_date == '2026-05-01'

Production Callouts
CI pipelineThe test suite runs in under 10 seconds with no external dependencies. Add .github/workflows/test.yml running uv run pytest on every push to main. test_smoke.py skips gracefully in keyless CI environments.
Cost accuracyPricing constants in pipeline_cost.py are approximate and dated. For production billing accuracy, fetch current pricing from each provider's API or a maintained pricing database rather than hardcoded constants. The PRICING_DATE field in every response makes staleness visible.
Property-based testingUse Hypothesis to generate edge cases for classify_query() automatically. Particularly valuable for the serial number regex — Hypothesis finds boundary cases that hand-written tests miss.
