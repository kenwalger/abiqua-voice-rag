The Abiqua Collection
Voice RAG System — Test Suite Specification
Spec version 1.0  ·  Component: Testing  ·  Status: Draft
Overview
This document specifies the test suite for the Abiqua Collection Voice RAG system. The suite targets three high-impact areas: query classification logic, Pydantic schema contracts, and Rime TTS integration error handling. It deliberately excludes end-to-end tests against live Atlas and Rime APIs in CI — those dependencies are too slow, too expensive, and too fragile for automated runs.

The goal is not coverage percentage. The goal is a test suite that catches the failures that matter most — misclassified queries silently returning wrong data, malformed API responses bypassing schema validation, and Rime error states propagating incorrectly to the client.

Scope~25 tests across three categories. All tests run without live external API calls. pytest is the test runner. No coverage badge is required or targeted — the suite demonstrates testing judgment, not metric optimization.
Testing Philosophy
Each of the three test categories maps to a specific risk in the production system:

CategoryDescriptionQuery classificationA misclassified query silently returns wrong data. A serial number classified as natural_language hits all three collections and may return a semantically similar but incorrect firearm. No error is raised. This is the highest-risk silent failure in the pipeline and the most important category to test.Pydantic schema contractsThe FastAPI request and response models are the contract between the Python backend and the TypeScript frontend. If a nullable field is not typed as Optional, a real record with a null year_end will cause a 500 in production. Schema tests validate the contract without requiring a running server.Rime integrationThe Rime integration handles external API errors and maps them to appropriate HTTP responses. A 429 from Rime must return a 503 to the client, not a 500 or a 200 with corrupted audio. These behaviors are testable with mocked HTTP responses and are critical to production reliability.

Category 1 — Query Classification
Tests for the classify_query() function in orchestrator.py. This function is pure Python with no external dependencies — no mocking required. All tests are synchronous.

# tests/test_classification.py
import pytest
from app.orchestrator import classify_query, extract_serial_number

class TestClassification:

    def test_plain_serial_number(self):
        result = classify_query('143960')
        assert result == 'serial_number'

    def test_hash_prefix_serial(self):
        result = classify_query('#91000')
        assert result == 'serial_number'

    def test_word_prefix_serial(self):
        result = classify_query('serial 45231')
        assert result == 'serial_number'

    def test_natural_language(self):
        result = classify_query(
            'tell me about the 1905 New Departure shipped to China'
        )
        assert result == 'natural_language'

    def test_model_name_only(self):
        result = classify_query('New Departure')
        assert result == 'natural_language'

    def test_three_digits_not_serial(self):
        result = classify_query('123')
        assert result == 'natural_language'

    def test_ten_digits_not_serial(self):
        result = classify_query('1234567890')
        assert result == 'natural_language'

    def test_mixed_query_with_serial(self):
        result = classify_query('serial 143960 nickel finish')
        assert result == 'serial_number'

    def test_extract_from_word_prefix(self):
        serial = extract_serial_number('serial 143960')
        assert serial == '143960'

    def test_extract_from_bare(self):
        serial = extract_serial_number('143960')
        assert serial == '143960'

Implementation
# tests/test_schema.py
import pytest
from pydantic import ValidationError
from app.main import QueryRequest, QueryResponse, ImageRef, SourceMeta, ApiError

class TestQueryRequest:

    def test_valid_query_only(self):
        req = QueryRequest(query='143960')
        assert req.query == '143960'
        assert req.top_k == 5  # default

    def test_valid_with_all_fields(self):
        req = QueryRequest(query='New Departure', voice_id='colby', top_k=10)
        assert req.voice_id == 'colby'
        assert req.top_k == 10

    def test_rejects_empty_query(self):
        with pytest.raises(ValidationError):
            QueryRequest(query='x')  # min length 2

    def test_rejects_long_query(self):
        with pytest.raises(ValidationError):
            QueryRequest(query='x' * 501)

    def test_rejects_top_k_over_max(self):
        with pytest.raises(ValidationError):
            QueryRequest(query='143960', top_k=21)


class TestQueryResponse:

    def test_valid_response_with_null_year_end(self):
        resp = QueryResponse(
            narration_text='Test narration.',
            audio_b64='dGVzdA==',
            audio_mime='audio/mpeg',
            image_count=0,
            image_refs=[],
            source_meta=SourceMeta(
                model='.32 New Departure',
                serial_range='143960',
                year_start=1905,
                year_end=None,   # null is valid
                record_count=1,
                confidence=1.0,
            ),
            query_echo='143960',
            latency_ms=1200,
        )
        assert resp.source_meta.year_end is None

    def test_empty_image_refs(self):
        # image_refs can be empty list — should not raise
        resp = QueryResponse(
            narration_text='Test.',
            audio_b64='dGVzdA==',
            audio_mime='audio/mpeg',
            image_count=0,
            image_refs=[],
            source_meta=SourceMeta(model='Test', serial_range='0',
                year_start=None, year_end=None,
                record_count=0, confidence=0.0),
            query_echo='test',
            latency_ms=100,
        )
        assert resp.image_refs == []

    def test_image_ref_null_caption(self):
        ref = ImageRef(
            image_id='abc123',
            url='https://example.com/img.webp',
            caption=None,
            primary=True,
        )
        assert ref.caption is None

    def test_source_meta_all_null_years(self):
        meta = SourceMeta(
            model='Unknown', serial_range='0',
            year_start=None, year_end=None,
            record_count=0, confidence=0.0,
        )
        assert meta.year_start is None
        assert meta.year_end is None

    def test_api_error_shape(self):
        err = ApiError(
            ok=False,
            status=422,
            error='no_records_found',
            detail='No matching records for serial number 999999.',
        )
        assert err.ok is False
        assert err.status == 422

Implementation
# tests/test_rime.py
import base64, json, pytest
from unittest.mock import patch, MagicMock
from urllib.error import HTTPError, URLError
from app.rime import synthesize, get_voices, _clean_narration, RimeResult

FAKE_MP3 = b'\xff\xfb\x90\x00' + b'\x00' * 100  # minimal mp3-like bytes
FAKE_MP3_B64 = base64.b64encode(FAKE_MP3).decode('utf-8')

def make_mock_response(body: bytes, status: int = 200):
    mock = MagicMock()
    mock.read.return_value = body
    mock.status = status
    mock.__enter__ = lambda s: s
    mock.__exit__ = MagicMock(return_value=False)
    return mock


class TestSynthesize:

    @pytest.mark.asyncio
    async def test_returns_rime_result_on_success(self):
        mock_resp = make_mock_response(FAKE_MP3)
        with patch('urllib.request.urlopen', return_value=mock_resp):
            result = await synthesize('The New Departure was produced in 1887.')
        assert isinstance(result, RimeResult)
        assert result.audio_mime == 'audio/mpeg'
        assert result.audio_b64 == FAKE_MP3_B64

    @pytest.mark.asyncio
    async def test_audio_b64_decodes_correctly(self):
        mock_resp = make_mock_response(FAKE_MP3)
        with patch('urllib.request.urlopen', return_value=mock_resp):
            result = await synthesize('Test narration.')
        decoded = base64.b64decode(result.audio_b64)
        assert decoded == FAKE_MP3

    @pytest.mark.asyncio
    async def test_uses_default_voice_when_none(self):
        mock_resp = make_mock_response(FAKE_MP3)
        with patch('urllib.request.urlopen', return_value=mock_resp) as mock_open:
            result = await synthesize('Test.', speaker=None)
        assert result.speaker == 'colby'  # RIME_DEFAULT_VOICE

    @pytest.mark.asyncio
    async def test_uses_provided_speaker(self):
        mock_resp = make_mock_response(FAKE_MP3)
        with patch('urllib.request.urlopen', return_value=mock_resp):
            result = await synthesize('Test.', speaker='grove')
        assert result.speaker == 'grove'

    @pytest.mark.asyncio
    async def test_401_raises_api_error(self):
        err = HTTPError(url='', code=401, msg='Unauthorized',
                        hdrs=None, fp=MagicMock())
        err.read = lambda: b'{"error": "invalid_api_key"}'
        with patch('urllib.request.urlopen', side_effect=err):
            with pytest.raises(RuntimeError) as exc_info:
                await synthesize('Test.')
        assert 'rime_api_error:401' in str(exc_info.value)

    @pytest.mark.asyncio
    async def test_429_raises_api_error(self):
        err = HTTPError(url='', code=429, msg='Too Many Requests',
                        hdrs=None, fp=MagicMock())
        err.read = lambda: b'{"error": "rate_limit_exceeded"}'
        with patch('urllib.request.urlopen', side_effect=err):
            with pytest.raises(RuntimeError) as exc_info:
                await synthesize('Test.')
        assert 'rime_api_error:429' in str(exc_info.value)

    @pytest.mark.asyncio
    async def test_url_error_raises_unreachable(self):
        with patch('urllib.request.urlopen',
                   side_effect=URLError(reason='Connection refused')):
            with pytest.raises(RuntimeError) as exc_info:
                await synthesize('Test.')
        assert 'rime_unreachable' in str(exc_info.value)


class TestCleanNarration:

    def test_strips_underscores(self):
        result = _clean_narration('_Shipped_ in 1905.')
        assert '_' not in result
        assert 'Shipped' in result

    def test_strips_bold_asterisks(self):
        result = _clean_narration('**factory letter** on file.')
        assert '*' not in result
        assert 'factory letter' in result

    def test_strips_markdown_links(self):
        result = _clean_narration('[view record](https://example.com)')
        assert 'view record' in result
        assert 'https' not in result


class TestGetVoices:

    @pytest.mark.asyncio
    async def test_returns_voice_list(self):
        fake_voices = [{'id': 'colby', 'name': 'Colby', 'preview_url': None}]
        mock_resp = make_mock_response(json.dumps(fake_voices).encode())
        with patch('urllib.request.urlopen', return_value=mock_resp):
            result = await get_voices()
        assert result == {'voices': fake_voices}

    @pytest.mark.asyncio
    async def test_raises_on_network_failure(self):
        with patch('urllib.request.urlopen',
                   side_effect=URLError(reason='Name resolution failed')):
            with pytest.raises(RuntimeError):
                await get_voices()

Production Callouts
End-to-end testsDemo: manual curl validation only. Production: add pytest-recording or VCR.py to record and replay real Atlas and Rime API responses as cassettes. This gives you integration test coverage without live API calls in CI and without the brittleness of pure mocks.
CI pipelineDemo: tests run locally only. Production: GitHub Actions workflow running uv run pytest on every push to main. Add a simple workflow file at .github/workflows/test.yml. The test suite as specced runs in under 5 seconds with no external dependencies.
Property-based testingDemo: fixed input examples. Production: use Hypothesis to generate edge cases for query classification automatically. Particularly valuable for the serial number regex — Hypothesis will find boundary cases (e.g. numbers with leading zeros, mixed alphanumeric strings) that hand-written tests miss.
Frontend testsDemo: no frontend tests. Production: Vitest for React component unit tests, Playwright for browser-level end-to-end tests covering the full audio playback flow. The AudioPlayer component is the highest-value frontend test target given the autoplay and data URI complexity.
